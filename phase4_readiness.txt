     - `raw_output_json = None`

- Global PII Pattern Masking (Regex maskers for SSNs, credit cards, emails, IP addresses, JWT tokens).
- Automatic Response Serializer Redaction Middleware.

  1. Accept `tenant_id: UUID` in service / repository method parameters.

  3. Resolve `tenant_id` at the API router layer via standard auth dependencies (`get_current_user`, `get_tenant_id`).
